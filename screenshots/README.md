# Screenshot capture checklist

Use **real captures from the running project**. Do not use generated mockups as technical evidence.

Recommended recruiter screenshots:

1. Main dashboard with 10 rooms streaming temperature, humidity and energy data.
2. Injected anomaly with the resulting alert visible.
3. Invalid event isolated in the dead-letter queue.
4. Optional backend evidence from Swagger showing recent readings or analytics.

Keep all captures based on synthetic/demo data only.
